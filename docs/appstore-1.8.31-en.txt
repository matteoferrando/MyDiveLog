MORE ROBUST DOWNLOADS
• The Aqualung i330R joins the field-tested models: 71 dives downloaded from a unit in everyday use.
• Aqualung i330R: after a download stopped halfway, the next connection no longer mistakes leftovers from the previous read for an answer.
• Aqualung i330R and Apeks DSX: if the computer no longer accepts the saved code, for example after a reset, the app asks for the new PIN shown on the computer's screen instead of stopping.
• If a download stops and the next attempt fails, the final screen says how many dives are already saved in your logbook and what to do if the computer has more. It used to say that none had been saved.
• If the computer is slow to start sending data, the app makes up to three attempts instead of giving up after the first.
• For many computers the model decides how the data is read: the app now goes by the model the computer reports when it connects, even if a different one was picked from the list, and corrects the name too where possible.
• Mares: the app tells models with built-in Bluetooth apart from those using the BlueLink Pro adapter and only offers the right kind, since a wrong model could keep the download from starting. The Puck Pro Ultra is no longer mistaken for the Puck Pro.
• Mares: an out-of-range value in the computer's memory no longer stops the read.
• Halcyon Symbios: with Bluetooth protocol 1.30 the download no longer stops with "Unexpected packet length".
• McLean Extreme: the app waits for the first answer, which takes a few seconds, instead of repeating the request.
• Cressi Goa and Cartesio are recognized even when they advertise an old-style Bluetooth name.

PLANNER
• On closed circuit, gases can now also be set as "bailout".
• Under the bailout cylinder's consumption the right gas now appears, no longer the diluent.
• Damaged saved data, for example from a corrupted backup, no longer crashes the page and is no longer offered as the starting point of a repetitive dive, where it would have underestimated tissue loading.

ALSO
• On iPhone and Mac, system controls (Cancel, Done, Copy, Paste) and the Bluetooth permission prompt follow the device language, Italian or English.
• Dive page: vertical speed and the decompression line are correct even when the file's samples are out of time order.
• The gradient factor slider is larger and easier to use with a finger.
• Shearwater Cloud import: a truncated file is rejected instead of being read with empty fields.

More than 3,000 automated checks, all passing.
