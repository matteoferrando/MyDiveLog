The two answers

Over Bluetooth: put the computer in pairing mode, tap “Search for the computer”, and the dives come in. No cable, no file, no manufacturer software in the way. Dives you already have are enriched, not duplicated.

File only: the data does not leave over Bluetooth to anything but the manufacturer’s own app. This is the case for Garmin Descent watches, which send everything to Garmin Connect: export from there and import here, and the result is the same.

If something does not work the way this page says, tell us: that is how it gets fixed.

If your computer is not listed: files

MyDiveLog recognises seven formats by content, not by extension, so you do not need to know what that file is: drag it in and that is all.

  • UDDF — the universal logbook exchange format. Almost everything exports it.
  • Subsurface (.ssrf, .xml) — the native file too, no conversion.
  • Shearwater Cloud — XML export, and the device’s native log.
  • Garmin FIT — what comes out of Garmin Connect.
  • Scubapro LogTRAK (.logtrak).
  • CSV or TSV — any spreadsheet with one row per dive.
  • MyDiveLog JSON backup, to carry everything from one device to another.

Got a Mares, a Suunto or an Oceanic whose software does not export UDDF? Go through Subsurface: it reads almost everything and saves in a format we read natively.
